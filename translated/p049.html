3.21คำสั่ง Panel Condition Memory (Panel Condition Memory Commands)

เรียกคืน (Recall)
PCLType 2เรียกคืนค่า Panel Condition
Argument 1
0: ค่าเริ่มต้น (Default)  1 ถึง 50: หมายเลข Panel Condition Memory
บันทึก (Save)
PCSType 2บันทึกลง Panel Condition Memory
Argument 1
หมายเลข Panel Condition Memory: 1 ถึง 50
ลบ (Delete)
PCDType 2ลบค่า Panel Condition
Argument 1
หมายเลข Panel Condition Memory: 1 ถึง 50
เรียกคืนอัตโนมัติ (Auto Recall)
PCAType 2เปลี่ยนวิธีการเริ่มต้นระบบด้วย Panel Condition
Argument 1
1: เริ่มด้วยเงื่อนไขก่อนหน้า (Start with previous condition)  2: เริ่มด้วยเงื่อนไขใหม่ (Start with new condition)  3: เริ่มด้วยเงื่อนไขที่ระบุ (Start with specified condition)
หมายเลข Panel Condition (Panel Condition Number)
DPCType 2ระบุหมายเลข Panel Condition สำหรับโหลด/บันทึก
Argument 1
1 ถึง 50: หมายเลข Panel Condition Memory
PASType 3อ่านวิธีการเริ่มต้นระบบด้วย Panel Condition
Read value 1
0: เงื่อนไขก่อนหน้า (Previous condition)  1: โปรเจกต์ใหม่ (New project)  2: โปรเจกต์ที่ระบุ (Specified project)
MPAType 3อ่านหมายเลข Panel Condition ที่ใช้งานอยู่
Read value 1
1 ถึง 50: หมายเลข Panel Condition Memory
การควบคุม (Control)
RPLType 2ตั้งค่าฟังก์ชันอ่าน Panel Condition เป็น ON หรือ OFF
Argument 1
0: OFF  1: ON
RIPType 3อ่านสถานะของฟังก์ชันอ่าน Panel Condition (ON หรือ OFF)
Read value 1
0: OFF  1: ON
ป้ายชื่อ (Label)
LBCType 3อ่านเงื่อนไขป้ายชื่อ (Label)
Read value 1
ข้อความของเงื่อนไขป้ายชื่อ (Character string of the label condition)
