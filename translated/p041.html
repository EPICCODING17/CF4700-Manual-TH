3.17คำสั่งฟังก์ชัน Display (Display Function Commands)

ประเภทการแสดงผล (Display Type)
ATIType 1แสดงรูปคลื่นสัญญาณตามเวลา (Time waveform)
ASPType 1แสดง Power Spectrum
MAGType 1แสดงค่า MAG
PHSType 1สลับไปแสดงผล Phase
PSDType 1สลับไปแสดงผล Power Spectrum Density
O3SType 1แสดงผล 1/3 Octave
O1SType 1แสดงผล 1/1 Octave
AHIType 1แสดง Histogram
PDFType 1สลับไปแสดงผล Probability Density Function (PDF)
CDFType 1สลับไปแสดงผล Probability Density Distribution Function (CDF)
LSTType 1แสดงผลแบบ List
DOVType 1สลับไปแสดงผลแบบซ้อนทับ (Overlay)
DSPType 1สลับไปแสดงผลแบบแยกหน้าจอ (ยกเลิก Overlay)
หน้าจอคู่ (Dual Screen)
SECType 1สลับไปแสดงผลแบบหน้าจอคู่ (Dual Screen)
เมื่อสลับเป็นหน้าจอคู่แล้ว คำสั่งแสดงผลที่ส่งตามมาต่อจากคำสั่งนี้จะถูกกำหนดให้กับหน้าจอล่าง
หน้าจอล่าง (1) (Lower (1) Screen)
LDCType 3อ่านประเภทการแสดงผลของหน้าจอล่าง (หรือหน้าจอที่ 1)
Read value 1
1: Time waveform  21: Spectrum  49: Histogram  53: Octave
Read value 2
1: REAL or PDF  2: IMAG or CDF  3: MAG  4: PHASE  7: OCTAVE  9: LIST
LXAType 3อ่านค่าสเกลแกน X ของหน้าจอล่างในโหมดหน้าจอคู่ หรือของข้อมูลแสดงผลหน้าจอเดี่ยว
