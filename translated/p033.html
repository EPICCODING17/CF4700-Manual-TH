3.11คำสั่ง RS-232C Interface (RS-232C Interface Commands)

RS-232C
R2BType 3อ่านความเร็วการสื่อสาร (bps)
Read value 1
0: 1200  1: 2400  2: 4800  3: 9600  4: 19200  5: 38400  6: 57600  7: 115200
R2CType 3อ่านความยาวข้อมูล (Data bit length)
Read value 1
0: 7  1: 8
R2PType 3อ่านการตรวจสอบพาริตี้ (Parity check)
Read value 1
0: None  1: Odd  2: Even
R2SType 3อ่านความยาว stop bit
Read value 1
0: 1  1: 2
R2FType 3อ่านการจับมือสื่อสาร (Handshake / Flow control)
Read value 1
0: None  1: XON/OFF  2: Hardware
R2TType 3อ่านการตั้งค่าการขึ้นบรรทัดใหม่ (Line break/feed)
Read value 1
0: CR  1: CR+LF
