3.22คำสั่ง Data Memory (Data Memory Commands)

หมายเลข Data Memory (Data Memory Number)
MBSType 2ระบุหมายเลข data memory
Argument 1
หมายเลข 1 ถึง 300 ของ data memory
MBCType 3อ่านหมายเลข data memory
Read value 1
หมายเลข 1 ถึง 300 ของ data memory
MBUType 1เพิ่มหมายเลข data memory ขึ้น
MBDType 1ลดหมายเลข data memory ลง
DBLType 2ระบุหมายเลข data memory ที่จะโหลด/บันทึก
Argument 1
1 ถึง 999: หมายเลข Data Memory
ยูทิลิตี้ (Utilities)
MEMType 2ตั้งค่าตำแหน่งจัดเก็บข้อมูล (หน่วยความจำภายใน, การ์ด SD, แฟลชไดรฟ์ USB)
Argument 1
0: Internal  1: SD  2: USB (F:)  3: USB (G:)
MMTType 3อ่านตำแหน่งจัดเก็บข้อมูล (หน่วยความจำภายใน, การ์ด SD, แฟลชไดรฟ์ USB)
Read value 1
0: Internal  1: SD  2: USB (F:)  3: USB (G:)
Data Memory
MRCType 1เรียกคืนข้อมูล data memory (Recall)
MSTType 1บันทึกข้อมูล data memory (Save)
CMMType 2ระบุโหมดการบันทึก data memory
Argument 1
1: Manual   2: Auto
CMCType 1ล้างข้อมูล data memory ทั้งหมด
CBCType 2ล้างข้อมูล data memory ที่เลือก
Argument 1
1 ถึง 300: หมายเลขของ data memory
CPOType 1ตั้งค่า data memory ให้อยู่ในโหมดป้องกัน (Protect)
CPFType 1ยกเลิกโหมดป้องกันของ data memory
