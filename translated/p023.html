3.6คำสั่งตั้งค่า Analysis (Analysis Setting Commands)

การตั้งค่า Spectrum (Spectrum Setting)
CSFType 2ตั้งค่า frequency weighting
Argument 1
0: Flat (Z)  1: A-weight  2: C-weight
กระบวนการ Averaging (Averaging Process)
SASType 2ตั้งค่าเวลาของกระบวนการ averaging
Argument 1
0.1 ถึง 999.9
SAWType 2ตั้งค่าน้ำหนักของ exponential average
Argument 1
1 ถึง 65535
ASVType 3อ่านเวลาของกระบวนการ average
Read value 1
0.1 ถึง 999.9
AWVType 3อ่านน้ำหนักของ exponential average
Read value 1
1 ถึง 65535
การตั้งค่า Octave (Octave Setting)
CAOType 2ตั้งค่า frequency weighting สำหรับ bundled octave
Argument 1
0: OFF  1: A-weight  2: V.v  3: V.h
การคำนวณ Waveform (Waveform Calculation)
CAFType 3อ่านชนิดการคำนวณข้อมูล
Read value 1
0: OFF  1: +  2: −  3: *  4: /

Read value 1
−1: NG  0: All  1: OK
