การยืนยันการเชื่อมต่อ (Confirming the Connections)

หลังจากติดตั้งซอฟต์แวร์ client ตั้งค่าเงื่อนไขเครือข่าย และยืนยันการเชื่อมต่อตามที่กล่าวมาแล้ว ให้ตรวจสอบการเชื่อมต่อระหว่าง Client PC กับเครื่อง CF-4700 FFT Comparator ในขณะที่ Client PC และเครื่อง CF-4700 FFT Comparator เชื่อมต่อกันทางกายภาพด้วยสาย LAN ก่อนอื่นให้สั่งคำสั่ง ping เพื่อตรวจสอบว่าการสื่อสารในระดับ IP ของ TCP/IP ใช้งานได้หรือไม่ จากนั้นให้สั่งคำสั่งทดสอบเพื่อยืนยันว่าคำสั่งเหล่านั้นถูกส่งจาก Client PC ไปยังเครื่อง CF-4700 FFT Comparator ได้ตามปกติ และเครื่องวิเคราะห์ทำงานตอบสนองอย่างถูกต้อง

ขั้นตอนการใช้คำสั่ง ping ตรวจสอบการเชื่อมต่อ (ตรวจสอบการสื่อสารในระดับ IP)

คำสั่ง ping ใช้ตรวจสอบว่าการสื่อสารในระดับ IP ของ TCP/IP ใช้งานได้หรือไม่ โดย ping เป็นโปรแกรมที่ส่งแพ็กเก็ต ICMP และขอให้ฝั่งตรงข้ามตอบกลับ

1
เปิด Command Prompt

คลิกปุ่ม Start > All Programs > Accessories > Command Prompt เพื่อเปิด “Command Prompt”

2
สั่งคำสั่ง ping

ป้อน IP address ของเครื่อง CF-4700 FFT Comparator (ในตัวอย่างนี้คือ 192.168.3.59) ต่อท้ายคำสั่ง ping แล้วกดปุ่ม Enter บนคีย์บอร์ด หากเชื่อมต่อได้ถูกต้อง (ภาพซ้าย) จะมีการตอบกลับที่ถูกต้องสำหรับทุกแพ็กเก็ต หากเชื่อมต่อไม่ถูกต้อง (ภาพขวา) จะแสดงข้อความว่าไม่มีการตอบกลับ ให้ตรวจสอบสภาพการเชื่อมต่อและการตั้งค่า TCP/IP

ต้นฉบับมีภาพหน้าจอ Command Prompt ประกอบ 2 ภาพ (กรณีเชื่อมต่อสำเร็จ <Normal connection> และกรณีเชื่อมต่อผิดพลาด <Connection error>) จึงแสดงเป็นคำอธิบายแทนภาพ
