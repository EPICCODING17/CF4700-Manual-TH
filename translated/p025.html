3.9คำสั่งตั้งค่า System (System Setting Commands)

ไฟส่องหลังจอ (Back Light)
ELOType 2ตั้งค่าเวลา (นาที) จนกว่าไฟส่องหลังจอจะปิดโดยอัตโนมัติ
Argument 1
1 ถึง 60
การล็อกการป้อนข้อมูล (Operation Input Lock)
EKLType 2ล็อกหรือปลดล็อกหน้าจอ
Argument 1
0: OFF  1: ON
เสียงกดปุ่ม (Key Operation Sound)
EBOType 2เปิดหรือปิดเสียงกดปุ่ม (key operation sound)
Argument 1
0: OFF  1: ON
BONType 1สั่งเสียงบัซเซอร์กดปุ่ม
BOFType 1หยุดเสียงบัซเซอร์กดปุ่ม
การล็อกหน้าจอ (Screen Lock)
LOCType 3อ่านสถานะการป้องกันด้วยรหัสผ่านของการล็อกหน้าจอ (เปิดหรือปิด)
Read value 1
0: OFF  1: ON
เวลา (Time)
TRSType 2ตั้งเวลานาฬิกา
Argument 1
YY-MM-DD hh:mm
TRCType 3อ่านเวลา
Read value 1
YYYY/MM/DD hh:mm:ss
รีเซ็ต (Reset)
SREType 1รีเซ็ตเครื่องหลัก (main unit)
สภาวะการตั้งค่าจะกลับไปเป็นค่าเริ่มต้นจากโรงงาน (factory default)
