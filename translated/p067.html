เปิดคุณสมบัติของ Internet Protocol (TCP/IP)

เลือก “Local Area Connection” แล้วคลิกปุ่มขวาของเมาส์เพื่อเปิดเมนูป็อปอัป คลิกคำสั่ง [Properties (R)] ในเมนูป็อปอัป จะปรากฏหน้าต่าง “Local Area Connection Properties”

3
ตั้งค่า IP address ของ class C และ subnet mask

ก่อนอื่น ให้เลือก [Internet Protocol Version 4 (TCP/IPv4)] จากรายการการเชื่อมต่อใน “Local Area Connection Properties” แล้วคลิกปุ่ม [Properties (R)] จากนั้นในหน้าต่าง “Internet Protocol Version 4 (TCP/IPv4) Properties” ให้ตั้งค่า IP address และ subnet mask

คลิกเลือก [Use the following IP address (S)] เพื่อให้สามารถตั้งค่า IP address และ subnet mask ได้ ป้อน IP address (ในตัวอย่างนี้คือ 192.168.3.1) ที่ช่อง [IP Address (I)] และป้อน subnet mask (ในตัวอย่างนี้คือ 255.255.255.0) ที่ช่อง [Subnet Mask (U)] สุดท้าย คลิกปุ่ม [OK] ใน [Internet Protocol Version 4 (TCP/IPv4) Properties] เพื่อยืนยันการตั้งค่า
