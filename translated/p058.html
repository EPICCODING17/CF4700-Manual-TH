คำอธิบายการทำงาน (Command Description)
คำสั่งคำอธิบาย
AASหากส่งค่า 0, 1, 2, 3, 5 หรือ 6 เครื่องจะแปลงช่วงแรงดันตามตาราง Table of Voltage Range Conversion (AAS Command Argument) แล้วตั้งค่าให้กับ H/W
แปลง trigger level ตามตาราง Table of Trigger Level Conversion (Default Value) แล้วตั้งค่าเริ่มต้นให้กับ H/W
แปลง hysteresis ตามตาราง Table of Hysteresis Conversion (Default Value) แล้วตั้งค่าเริ่มต้นให้กับ H/W
หากส่งค่า 4 หรือ 7 เครื่องจะตั้งค่าช่วงแรงดันที่ส่งมาให้กับ H/W โดยตรง
AARส่งคืนค่า 4 (1 Vrms) หรือ 7 (31.6 Vrms)
AMPส่งคืนค่า 1 Vrms หรือ 31.6 Vrms
TLSหากค่าที่ส่งด้วย AAS เป็น 0, 1, 2, 3, 5 หรือ 6 อาร์กิวเมนต์จะถูกแปลงตามตาราง Table of Trigger Level Conversion แล้วตั้งค่าให้กับ H/W*1
*1 กระบวนการแปลงนี้จะทำงานต่อเนื่องไปจนกว่าจะเกิดเหตุการณ์ต่อไปนี้: ส่งคำสั่ง AAS 4 หรือ 7 / Condition Initialize / Reset (Home > System > Env Set > Reset) / Condition Load / เปลี่ยนค่าที่ตั้งด้วยตนเอง (ช่วงแรงดัน, trigger level, hysteresis) / ปิดเครื่อง
หากค่าที่ส่งด้วย AAS เป็น 4 หรือ 7 ค่าอาร์กิวเมนต์จะถูกตั้งให้กับ H/W โดยไม่มีการเปลี่ยนแปลง
TLCอ่านค่า trigger level % ที่ถูกตั้งไว้กับเครื่อง CF-4700
