ขั้นตอนการถอนการติดตั้ง (ลบ) Client Software (Client Software Uninstallation (Deletion) Procedure)

ซอฟต์แวร์ client เฉพาะทาง (CF-9000 ControlModule) ที่ติดตั้งไว้แล้วสามารถถอนการติดตั้งได้เหมือนกับซอฟต์แวร์ทั่วไป โดยคลิกปุ่ม Start > Control Panel > Programs and Functions เพื่อเปิดหน้าต่าง “Uninstall/Change Programs” จากนั้นคลิกขวาที่ Onosokki CF-9000 ControlModule ใน “Uninstall/Change Programs” แล้วเลือก “Uninstall (U)” จากเมนูป็อปอัป ทำตามข้อความและคำแนะนำที่ปรากฏบนหน้าจอเพื่อให้การถอนการติดตั้งเสร็จสมบูรณ์

2.2 การตั้งค่าเงื่อนไขเครือข่ายและการยืนยันการเชื่อมต่อ (Network Conditions Setting and Connection Confirmation)

อ้างอิงหัวข้อ “1.3 โครงสร้างการควบคุมภายนอก” ในหน้า 61 ด้านบน เพื่อเชื่อมต่อเครื่อง CF-4700 FFT Comparator กับ Client PC แล้วตั้งค่าเงื่อนไขเครือข่าย

การตั้งค่าเงื่อนไข Internet Protocol (Setting Internet Protocol Conditions)

หลังจากติดตั้งซอฟต์แวร์ client (CF-9000 ControlModule) เสร็จแล้ว ให้ตั้งค่า IP address หนึ่งชุดสำหรับ Client PC และอีกหนึ่งชุดสำหรับเครื่อง CF-4700 FFT Comparator โดยใช้ private IP address ของ class C (192.168.0.0 ถึง 192.168.255.255)

ข้อควรระวัง: รายละเอียดของรายการตั้งค่าเครือข่ายและขั้นตอนการทำงาน โปรดดูใน Help ของ OS ที่ใช้งาน หรือสอบถามผู้ดูแลระบบเครือข่าย Ono Sokki ไม่รับผิดชอบและไม่ชดใช้ความเสียหายใดๆ ที่เกิดจากผลของการดำเนินการดังกล่าว
