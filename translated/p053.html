3.25คำสั่ง Data Transfer (Data Transfer Commands)

จำนวนจุดข้อมูล (Number of Data Points)
BDLType 3อ่านจำนวนจุดข้อมูลภายในตัวเครื่อง
Argument 1
1: Time waveform  2: Power spectrum  3: Fourier spectrum  4: Histogram
Read value 1
จำนวนจุดข้อมูล
WLCType 3อ่านจำนวนข้อมูล waveform ที่กำลังแสดงผล
Argument 1
1: Lower screen  2: Upper screen
Read value 1
จำนวนจุดข้อมูล
การอ่านข้อมูล (Data Read)
LDDType 3อ่านข้อมูล waveform ของหน้าจอเดี่ยว หรือของหน้าจอล่างในโหมดสองหน้าจอ ในรูปแบบ ASCII code
Argument 1
1: X-axis value  2: Y-axis value  3: X-axis value, Y-axis value
Argument 2
ตำแหน่งเริ่มต้นของการส่งข้อมูล: 0 ขึ้นไป
Argument 3
ตำแหน่งสิ้นสุดของการส่งข้อมูล: 0 ขึ้นไป
Read value 1
ข้อมูล Waveform
UDDType 3อ่านข้อมูล waveform ของหน้าจอบน ในรูปแบบ ASCII code
Argument 1
1: X-axis value  2: Y-axis value  3: X-axis value, Y-axis value
Argument 2
ตำแหน่งเริ่มต้นของการส่งข้อมูล: 0 ขึ้นไป
Argument 3
ตำแหน่งสิ้นสุดของการส่งข้อมูล: 0 ขึ้นไป
Read value 1
ข้อมูล Waveform
