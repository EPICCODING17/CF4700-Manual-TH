3.12คำสั่ง Input Amplifier (Input Amplifier Commands)

แหล่งสัญญาณอินพุต (Signal Input Source)
SAVType 2แปลงแหล่งสัญญาณอินพุตเป็นสัญญาณแรงดันไฟฟ้า (Voltage signal)
Argument 1
1, 2: BNC
SAPType 2แปลงแหล่งสัญญาณอินพุตเป็นเซนเซอร์แบบพิกอัพ (Pickup sensor)
Argument 1
1, 2: Sensor
การคัปปลิ้ง (Coupling)
AACType 1สลับไปใช้การคัปปลิ้งแบบ AC (AC coupling)
ADCType 1สลับไปใช้การคัปปลิ้งแบบ DC (DC coupling)
ICCType 3อ่านสภาวะการคัปปลิ้งอินพุต (Input coupling)
Read value 1
0: DC coupling  1: AC coupling
ความไวอินพุต (Input Sensitivity)
ARSType 2ตั้งค่าช่วงแรงดันไฟฟ้าของช่องอินพุต (Input channel voltage range)
Argument 1
0: (fix Ch1)
Argument 2
0: 1 Vrms  1: 31.6 Vrms
ARGType 3อ่านช่วงแรงดันไฟฟ้าของช่องอินพุต
Argument 1
0: (fix Ch1)
Read value 1
0: 1 dBVrms  1: 31.6 dBVrms
AASType 2ตั้งค่าความไวอินพุต (Input sensitivity)
คำสั่งนี้มีไว้เพื่อความเข้ากันได้กับ CF-4500 หากเขียนโปรแกรมใหม่ ให้ใช้คำสั่ง ARS แทน
Argument 1
ช่วงแรงดันไฟฟ้า / ค่าสถานะ (Voltage range / Flag value)
0: 10 mVrms  1: 31.6 mVrms  2: 100 mVrms  3: 0.316 Vrms  4: 1 Vrms  5: 3.16 Vrms  6: 10 Vrms  7: 31.6 Vrms
AARType 3อ่านความไวอินพุต (Input sensitivity)
คำสั่งนี้มีไว้เพื่อความเข้ากันได้กับ CF-4500 หากเขียนโปรแกรมใหม่ ให้ใช้คำสั่ง ARG แทน
Read value 1
ช่วงแรงดันไฟฟ้า / ค่าสถานะ (Voltage range / Flag value)
0: 10 mVrms  1: 31.6 mVrms  2: 100 mVrms  3: 0.316 Vrms  4: 1 Vrms  5: 3.16 Vrms  6: 10 Vrms  7: 31.6 Vrms
AMPType 3อ่านความไวอินพุตเป็นค่าแรงดันไฟฟ้า (V)
Read value 1
