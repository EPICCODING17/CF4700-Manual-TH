เพิ่มการอ้างอิง (Reference) ของโมดูลควบคุม

ขั้นถัดไป ให้เพิ่มการอ้างอิงของโมดูลควบคุม

เลือกคำสั่ง Add Reference จากเมนู Project (P) เพื่อเปิดกล่องโต้ตอบ Reference Manager

คลิกปุ่ม Browse บนกล่องโต้ตอบ Reference Manager เพื่อเปิดกล่องโต้ตอบ Select File for Reference จากนั้นเลือกไฟล์ CF9000ControlModule.dll แล้วคลิกปุ่ม Add

ตัวอย่างต่อไปนี้คือตำแหน่งไฟล์ที่ C:\Program Files (x86)\Onosokki CF-9000\CF9000Control

CF9000ControlModule จะถูกเพิ่มเข้าไปในการตั้งค่าการอ้างอิงของ Solution Explorer ดังแสดงในรูปต่อไปนี้
