2.1 การติดตั้ง Client Software (Installing Client Software)

ติดตั้งซอฟต์แวร์เฉพาะทาง (CF-9000 Control Module) สำหรับควบคุมเครื่อง CF-4700 FFT Comparator ลงในเครื่องคอมพิวเตอร์ของลูกค้า

ข้อควรระวัง: ซอฟต์แวร์ client ตัวเดียวกับที่ใช้บนเครื่องวิเคราะห์ซีรีส์ CF-9000 ของ Ono Sokki ถูกนำมาใช้กับเครื่อง CF-4700 FFT Comparator
ขั้นตอนการติดตั้ง Client Software (Client Software Installation Procedure)
1
ใส่แผ่น CD ที่มีตัวติดตั้งลงในไดรฟ์

ใส่แผ่น Appendix CD ที่มาพร้อมกับเครื่อง CF-4700 FFT Comparator ลงในไดรฟ์ CD ของคอมพิวเตอร์ ใช้ Explorer เปิดโฟลเดอร์ Control ที่เก็บอยู่ในแผ่น Appendix CD เพื่อตรวจสอบว่ามีไฟล์ LanCtrlSetup.msi อยู่

2
ดำเนินการติดตั้ง

ดับเบิลคลิกไฟล์ LanCtrlSetup.msi ที่อยู่ในโฟลเดอร์ Control เพื่อเริ่มการติดตั้งซอฟต์แวร์ ตัวติดตั้ง (installer) จะเริ่มทำงาน คลิกปุ่ม Next บนตัวติดตั้งเพื่อดำเนินการติดตั้งต่อ เมื่อการติดตั้งเสร็จสมบูรณ์ จะแสดงข้อความ “Installation Complete” ให้คลิกปุ่ม Close

3
ตรวจสอบการติดตั้ง

เมื่อการติดตั้งเสร็จสมบูรณ์ จะมีการสร้างโฟลเดอร์ Onosokki CF-9000\CF9000Control ขึ้นภายใต้โฟลเดอร์ C:\Program Files\ หรือ C:\Program Files(x86)\ ใช้ Explorer ตรวจสอบว่าโฟลเดอร์ CF9000Control มีไฟล์ทั้ง 4 ไฟล์ต่อไปนี้ครบถ้วน: CF9000ControlModule.dll, CF9000ControlModule.tlb, CustumControl.dll, CustumControl.InstallState
