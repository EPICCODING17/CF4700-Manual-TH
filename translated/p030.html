คำสั่งนี้มีไว้เพื่อความเข้ากันได้กับ CF-4500 หากเขียนโปรแกรมใหม่ ให้ใช้คำสั่ง BCM แทน

0: OK หรือยังไม่ได้ตัดสิน  1: NG (fail)

CERType 3อ่านเงื่อนไขสิ้นสุดการตัดสินของ block comparator
ค่าจะถูกล้างกลับเป็นศูนย์โดยอัตโนมัติเมื่อ comparator เริ่มทำงาน และหลังจากอ่านคำสั่ง CER แล้ว
ใช้ไม่ได้กับ shape comparator
Read value 1
0: การตัดสินยังไม่สามารถสิ้นสุดได้  1: การตัดสินสิ้นสุดแล้ว
เริ่มทำงาน (Start)
CMTType 1สั่งให้ comparator เริ่มทำงาน
หยุดทำงาน (Stop)
CMSType 1สั่งให้ comparator หยุดทำงาน
ค่าที่ตั้ง (Set Value)
ABSType 2ตั้งค่าเงื่อนไขการตัดสินของ block comparator
Argument 1 (Argument 2)
0: SINGLE MODE (0: OFF, 1: ON)
0: TIMER (0: OFF, 1: ON)
2: START DELAY (0 ถึง 255 [s])
3: COMP TIME (0 ถึง 255 [s])
4: START CLEAR (0: OFF, 1: ON)
5: NG OUT (0: ONE, 1: ALL)
ABGType 3อ่านเงื่อนไขการตัดสินของ block comparator
Argument 1 (Read value)
0: SINGLE MODE (0: OFF, 1: ON)
0: TIMER (0: OFF, 1: ON)
2: START DELAY (0 ถึง 255 [s])
3: COMP TIME (0 ถึง 255 [s])
4: START CLEAR (0: OFF/1: ON)
5: NG OUT (0: ONE, 1: ALL)
