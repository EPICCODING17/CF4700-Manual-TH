3.8คำสั่ง Control Key (Control Key Commands)

ปุ่ม Control Key (Control Key)
KFUType 1ใช้ปุ่ม Frequency Range Up เพื่อเปลี่ยนช่วงความถี่ (frequency range)
KFDType 1ใช้ปุ่ม Frequency Range Down เพื่อเปลี่ยนช่วงความถี่ (frequency range)
KTRType 1ใช้ปุ่ม TRIG ON เพื่อเปลี่ยนการตั้งค่า trigger ON/OFF
KSAType 1ใช้ปุ่ม SAVE เพื่อบันทึกข้อมูลลงหน่วยความจำ
KAVType 1ใช้ปุ่ม AVG เพื่อสลับโหมดการคำนวณตามแต่ละโหมดการวัด
KSTType 1ใช้ปุ่ม START เพื่อเริ่มการวิเคราะห์
KPAType 1ใช้ปุ่ม PAUSE เพื่อหยุดโหมดการคำนวณตามแต่ละโหมดการวัดไว้ชั่วคราว (หรือสั่งการทำงานที่เทียบเท่า)
KSPType 1ใช้ปุ่ม STOP เพื่อหยุดการวิเคราะห์
KTIType 2ใช้ปุ่ม TIME เพื่อสลับชนิดข้อมูลของหน้าจอที่ใช้งานอยู่ไปเป็น time-axis waveform
Argument 1
0 fix [Ch1]
KSCType 2ใช้ปุ่ม SPECT เพื่อสลับชนิดข้อมูลของหน้าจอที่ใช้งานอยู่ไปเป็น power spectrum
Argument 1
0 fix [Ch1]
การควบคุมการวัด (Measurement Control)
COOType 1สั่งงานปุ่ม COMPARE
KCOType 1ใช้ปุ่ม COMPARE เพื่อแสดงหน้าจอ execution หรือเริ่มการตัดสิน (judgment)
SCOType 3อ่านสถานะไฟ LED ของปุ่ม COMPARE
Read value 1
0: OFF  1: ON
