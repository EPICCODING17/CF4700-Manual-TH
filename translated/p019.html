การตั้งค่า Sample (Sample Setting)
SSFType 2ตั้งค่าจำนวน sample
Argument 1
2: 256  3: 512  4: 1024  5: 2048  6: 4096  7: 8192  8: 16384
SCFType 2ตั้งค่าประเภทของ sample
Argument 1
0: Internal  1: External
ESLType 2ตั้งค่าโหมดระดับตรวจจับของ external sample
Argument 1
0 [ExtCh1]
Argument 2
0: TTL  1: Voltage
SAOType 2ตั้งค่าปริมาณ sample overlap
Argument 1
0: Max  1: 75%  2: 66.7%  3: 50%  4: 25%  5: 0%  6: Custom
SACType 2ตั้งค่าเปิดหรือปิดการยกเลิก sample A/D overflow
Argument 1
0: OFF  1: ON
SOFType 3อ่านปริมาณ sample overlap
Read value 1
0: Max  1: 75%  2: 66.7%  3: 50%  4: 25%  5: 0%  6: Custom
SADType 3อ่านสถานะการยกเลิก sample A/D overflow (เปิดหรือปิด)
Read value 1
0: OFF  1: ON
การประมวลผลก่อนแกนเวลา (Time-axis Preprocessing)
TIPType 2ตั้งค่าเปิดหรือปิดการยกเลิก DC (direct current)
Argument 1
0 fix [Ch1]
Argument 2
0: OFF  1: ON
TPDType 3อ่านสถานะการยกเลิก DC (direct current) (เปิดหรือปิด)
Argument 1
0 fix [Ch1]
Read value 1
0: OFF  1: ON
การตั้งค่าการวิเคราะห์ Tracking (Tracking Analysis Setting)
TTSType 2ตั้งค่าเวลารวมของการวิเคราะห์ time tracking
Argument 1
0.0 ถึง 600000.0
TAMType 3อ่านสถานะฟังก์ชัน schedule (เปิดหรือปิด)
Read value 1
0: OFF  1: ON
