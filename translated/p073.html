ตัวอย่างโปรแกรมควบคุมที่สร้างด้วย Visual Studio Express® 2012 (Example of Control Program Created with Visual Studio Express® 2012)

หัวข้อต่อไปนี้อธิบายขั้นตอนการสร้างโปรแกรมควบคุมภายนอกด้วยภาษา Visual C# โดยใช้ Microsoft Visual Studio Express® 2012

1
สร้างโปรเจกต์ใหม่

ขั้นแรก เปิดโปรแกรม Visual Studio Express® 2012

จากนั้นคลิกคำสั่ง New Project (P) ในเมนู File (F) เพื่อเปิดกล่องโต้ตอบ New Project

เลือก Visual C# Windows forms application ในกล่องโต้ตอบ New Project แล้วตั้งชื่อโปรเจกต์

ในที่นี้ใช้ชื่อโปรเจกต์เริ่มต้น "WindowsFormsApplication1" ในการสร้างโปรเจกต์

คลิกปุ่ม OK บนกล่องโต้ตอบ New Project

2
วางปุ่มคำสั่งลงบนฟอร์ม

คลิก Tool Box (X) จากเมนู View (V) เพื่อเปิดกล่องเครื่องมือ

จากนั้นคลิก common control ในกล่องเครื่องมือ แล้วเลือก [Button] ซึ่งปรากฏอยู่ด้านบนสุด

ปุ่มคำสั่ง (Button1) จะปรากฏบน [Design] เมื่อคลิก [Design] บนแท็บ Form1.cs
