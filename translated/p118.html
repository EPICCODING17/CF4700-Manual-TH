4.ภาคผนวก (Reference)

4.1ศัพท์เครือข่าย (Network Terms)

ที่อยู่ IP (IP Address)

ที่อยู่ IP คือหมายเลขที่ใช้ระบุอุปกรณ์แต่ละเครื่อง เช่น คอมพิวเตอร์ ในเครือข่าย

ในการสื่อสารแบบ TCP/IP อุปกรณ์แต่ละเครื่อง เช่น คอมพิวเตอร์ที่ใช้ในเครือข่าย จะต้องถูกกำหนดหมายเลขที่ประกอบด้วยตัวเลขคั่นด้วยจุด 4 ชุด เช่น “192.168.0.10” หมายเลขนี้คือที่อยู่ IP ซึ่งต้องไม่ซ้ำกันตลอดทั้งเครือข่าย

ที่อยู่ IP แบ่งเป็น 2 ชนิดตามโพรโทคอลอินเทอร์เน็ต ได้แก่ IPv4 และ IPv6 เครื่อง CF-4700 FFT comparator ใช้ IPv4

ที่อยู่ IP สาธารณะและที่อยู่ IP ภายใน (Global IP address and local IP address)

ที่อยู่ IP ยังแบ่งเป็น 2 ชนิดตามพื้นที่การใช้งาน ได้แก่ ที่อยู่ IP สาธารณะ (global IP address) ที่ใช้บนอินเทอร์เน็ต และที่อยู่ IP ภายใน (local IP address หรือ private IP address) ที่ใช้ภายใน LAN

ฟังก์ชันควบคุมภายนอกผ่าน LAN ของ CF-0947 ถูกออกแบบมาให้ควบคุมเครื่อง CF-4700 FFT comparator ผ่านเครื่องคอมพิวเตอร์ลูกข่าย (client PC) ในสภาพแวดล้อมที่ไม่ได้เชื่อมต่อกับอินเทอร์เน็ต (แบบ peer to peer) ดังนั้นจึงใช้ที่อยู่ IP ภายในที่แตกต่างกัน เพื่อให้สามารถใช้ที่อยู่ IP ใดก็ได้ที่ไม่ซ้ำกันภายในเครือข่ายนั้น

คลาสของที่อยู่ IP ที่ใช้ใน LAN (Classes of IP addresses used in LANs)

ที่อยู่ IP แบ่งออกเป็น 3 คลาสตามจำนวนคอมพิวเตอร์ที่ประกอบกันเป็นเครือข่าย ได้แก่ คลาส A สำหรับเครือข่ายขนาดใหญ่ คลาส B สำหรับเครือข่ายขนาดกลาง และคลาส C สำหรับเครือข่ายขนาดเล็ก

ที่อยู่ IP ในคลาสเดียวกันต้องใช้อยู่ในเครือข่ายเดียวกัน ที่อยู่ IP ประกอบด้วยตัวเลข 4 ชุดคั่นด้วยจุด และตัวเลขชุดแรกจะบ่งบอกคลาสของที่อยู่ IP นั้น

ตัวอย่างที่อยู่ IP: 192.168.0.1

หมายเหตุ: 127 และ 224 ถึง 255 จะไม่ถูกใช้เป็นที่อยู่ IP ทั่วไป

เลขตัวแรกของที่อยู่ IPคลาสขนาดเครือข่าย (จำนวนคอมพิวเตอร์)
1 to 126Class Aเครือข่ายขนาดใหญ่ (สูงสุดประมาณ 16 ล้านเครื่อง)
128 to 191Class Bเครือข่ายขนาดกลาง (สูงสุดประมาณ 65,000 เครื่อง)
192 to 223Class Cเครือข่ายขนาดเล็ก (สูงสุด 254 เครื่อง)

เครื่องคอมพิวเตอร์ลูกข่าย (client PC) และเครื่อง CF-4700 FFT comparator ที่มีฟังก์ชันควบคุมภายนอกผ่าน LAN ของ CR-4700 ใช้ที่อยู่ IP ภายในเฉพาะของคลาส C ดังนี้

คลาส C: 192.168.0.0 ถึง 192.168.255.255 (ค่าเริ่มต้น: 192.168.3.59)

ซับเน็ตมาสก์ (Subnet mask)

การใช้ซับเน็ตมาสก์ (subnet mask) ช่วยแบ่งย่อยที่อยู่ IP ได้ละเอียดขึ้น

ในที่อยู่ IP ส่วนที่เป็น “1” ของซับเน็ตมาสก์บ่งบอกถึง “ที่อยู่เครือข่าย (network address)” และส่วนที่เป็น “0” บ่งบอกถึง “ที่อยู่โฮสต์ (host address)”

ตัวอย่างเช่น ซับเน็ตมาสก์ “255.255.255.240” มีค่า “0000” อยู่เฉพาะ 4 บิตล่าง ซึ่งช่วยให้แบ่งย่อยได้อีก 16 กลุ่ม กลุ่มละ 16 ที่อยู่โฮสต์

ที่อยู่ IP ที่มาพร้อมซับเน็ตมาสก์ เรียกว่า “ที่อยู่ IP แบบขยาย (extended IP address)”
