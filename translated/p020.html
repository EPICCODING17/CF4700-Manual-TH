3.2คำสั่งตั้งค่า Display (Display Setting Commands)

การตั้งค่า Layout (Layout Setting)
AGNType 2ตั้งค่าจำนวนหน้าจอที่แสดงในแนวตั้งและแนวนอน
Argument 1
จำนวนหน้าจอแนวนอน
Argument 2
จำนวนหน้าจอแนวตั้ง
FROType 2ตั้งค่าเปิดหรือปิดฟังก์ชัน graph overlay
Argument 1
0: OFF  1: ON
FOOType 3อ่านสถานะฟังก์ชัน graph overlay (เปิดหรือปิด)
Read value 1
0: OFF  1: ON
การตั้งค่า Cursor (Cursor Setting)
MSOType 1เลื่อน cursor ไปยังจุด overall
CUSType 2ตั้งค่าเปิดหรือปิดฟังก์ชัน search enhancement
Argument 1
0: OFF  1: ON
CUYType 2ตั้งค่าการแสดงผลแกน Y สำหรับ delta cursor
Argument 1
0: OFF  1: Difference between two points  2: Partial overall
CMFType 3อ่านโหมด cursor ของแกน Y
Read value 1
0: Peak  1: Search  2: Delta
CSEType 3อ่านสถานะฟังก์ชัน search enhancement (เปิดหรือปิด)
Read value 1
0: OFF  1: ON
CYDType 3อ่านการแสดงผลแกน Y สำหรับ delta cursor
Read value 1
0: OFF  1: Difference between two points  2: Partial overall
การตั้งค่า Graph (Graph Setting)
SGGType 2แสดงหรือซ่อนเส้น grid บนกราฟ
Argument 1
0: OFF  1: ON
GTGType 3อ่านชนิดเส้นของ grid บนกราฟ
Read value 1
0: Solid line  1: Dotted line  2: Dashed line  3: Dash-dot line  4: Dash-two dot line
