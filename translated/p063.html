1.3 โครงสร้างการควบคุมภายนอก (External Control Configuration)

ต่อไปนี้เป็นตัวอย่างการต่อระบบเพื่อใช้งานฟังก์ชัน LAN External Control ของเครื่อง CF-4700

Client PC (+ CF9000ControlModule.dll)  ⇔  Cross/straight LAN cable (category 6)  ⇔  LAN port  ⇔  CF-4700 FFT Comparator

หรือเชื่อมผ่าน USB: Client PC  ⇔  USB-LAN adapter (แนะนำโดย Ono Sokki)  ⇔  USB port  ⇔  CF-4700 FFT Comparator

ข้อสำคัญ: ห้ามเชื่อมต่อเครื่อง CF-4700 FFT Comparator เข้ากับระบบ LAN ของสำนักงานโดยเด็ดขาด Ono Sokki จะไม่รับผิดชอบและไม่ชดใช้ความเสียหายใดๆ ที่เกิดจากผลของการเชื่อมต่อดังกล่าว
ข้อควรระวัง:
  • สำหรับ USB-LAN adapter ที่ใช้งานร่วมกับเครื่อง CF-4700 FFT Comparator ได้ ติดต่อสำนักงานขายหรือตัวแทนจำหน่าย Ono Sokki ใกล้บ้านท่าน
  • ไม่รองรับการเชื่อมต่อผ่าน LAN hub ให้เชื่อมต่อเครื่องวิเคราะห์เข้ากับ LAN port โดยตรง หรือผ่าน USB-LAN adapter เข้ากับ USB port เท่านั้น
  • หากฟังก์ชัน LAN External Control ของ CF-4700 ทำงานผิดปกติ ติดต่อสำนักงานขายหรือตัวแทนจำหน่าย Ono Sokki ใกล้บ้านท่าน
  • ฟังก์ชัน LAN External Control ของ CF-4700 ถูกพัฒนาขึ้นสำหรับผู้ใช้งานที่มีประสบการณ์และความรู้ด้านการเขียนโปรแกรมเครือข่าย LAN โปรดเข้าใจล่วงหน้าว่า Ono Sokki ไม่สามารถรับคำถามเกี่ยวกับเครือข่ายและ TCP/IP ได้
