วิธี GetData ทั้งบรรทัด (All-line data acquisition method)
GetData (XDatas () As Single, YDatas () As Single) As String
คำอธิบาย
อ่านข้อมูลทั้งบรรทัดของกราฟที่ใช้งานอยู่ (Acquisition of all line data of active graphs)
Argument 1
ข้อมูลแกน X (X-axis data)
Argument 2
ข้อมูลแกน Y (Y-axis Data)
ค่าที่คืนกลับ
คืนค่า "0" เมื่ออ่านข้อมูลสำเร็จ / คืนค่า "Time out error." เมื่อเกิด timeout / คืนค่า "Receive error." เมื่อเกิดข้อผิดพลาดจากข้อยกเว้น (exception)

SetIPAddress (newIPAddress As String) As String
คำอธิบาย
สามารถตั้งค่า IP address ได้ (An IP address can be set.)
• เมธอดนี้ไม่สามารถเขียนทับ IP address ของตัวเครื่อง CF-4700 comparator ได้
• หลังจากเริ่มโปรแกรมแล้ว ให้ส่งเมธอดนี้เป็นลำดับแรกเพื่อระบุ IP address ของ CF-4700 FFT comparator (ไม่จำเป็นต้องส่งซ้ำอีก)
Argument 1
IP address (IPv4)
ค่าที่คืนกลับ
คืนค่า 0 (สำเร็จ) หรือ −1 (ล้มเหลว)
