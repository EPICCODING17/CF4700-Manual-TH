3.19คำสั่งฟังก์ชัน Search (Search Function Commands)

การค้นหา (Search)
SONType 1ตั้งค่าฟังก์ชันค้นหาเป็น Search
SPPType 1ตั้งค่าฟังก์ชันค้นหาเป็น Peak
DONType 1ตั้งค่าฟังก์ชันค้นหาเป็น Delta
เคอร์เซอร์ Delta (Delta Cursor)
DCSType 1ตั้งค่าเคอร์เซอร์ Delta
ตำแหน่งค้นหา (Search Point)
SHLType 2เลื่อนเส้นเคอร์เซอร์ไปยังตำแหน่งใดก็ได้บนหน้าจอล่าง
ใช้งานได้เมื่อฟังก์ชันค้นหาถูกสลับเป็น Search หรือ Delta
ใช้คำสั่ง SON เพื่อเปลี่ยนฟังก์ชันค้นหาเป็น Search และใช้คำสั่ง DON เพื่อเปลี่ยนเป็น Delta หรือแตะปุ่มตั้งค่าตามลำดับนี้เพื่อเปลี่ยนการตั้งค่า: Home > Display > Cursor > Mode
